# Paper / spiderweb throw — candidates

**Engine events:** `WEB_STARTED` (the tether shoots out), `ATOM_COLLECTED` (the atom is reeled in).
**Wanted feel:** stretch → release → soft physical movement. Elastic, lightweight, tactile, tether-like.
**Excluded by brief:** superhero / Spider-Man "thwip", franchise audio, cinematic risers, aggressive impacts, cartoon boings.

Nobody listened to these. Every character note is inferred from the asset page's
title, tags, description, duration and sample rate. **These are audition lists,
not selections.**
